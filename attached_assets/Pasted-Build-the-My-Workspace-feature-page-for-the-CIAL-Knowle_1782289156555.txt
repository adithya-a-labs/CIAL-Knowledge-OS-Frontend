Build the “My Workspace” feature page for the CIAL Knowledge OS dashboard, matching the attached reference image as closely as possible.

This page represents each employee’s private, compartmentalized knowledge workspace. It must feel like a secure personal knowledge vault inside the larger CIAL Knowledge OS.

Core concept:
Each employee gets a private 5 GB storage area where they can upload documents, notes, reports, vendor manuals, and personal references. These files are visible only to that employee. They are not added to the central enterprise repository. However, the AI Assistant can use both the central CIAL Knowledge Base and the employee’s private documents when the user chooses Hybrid Mode.
